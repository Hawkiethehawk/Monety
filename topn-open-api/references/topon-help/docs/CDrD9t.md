# 授权和风险提示说明

为提高开发者的变现效率，TopOn为开发者提供了Open API公开接口功能，欢迎您使用该功能。本说明向您详细阐明了您为使用TopOn Open API功能而需要进行的授权内容以及您需要同意并严格遵守的事项。若您不同意这些授权内容或事项，请您勿使用Open API功能。一旦您使用TopOn Open API服务并将Publisher Key在第三方平台完成相关绑定，即表明您已明确理解、同意了本说明的全部内容并已向TopOn作出了明确授权。

1. 您明确理解并同意，您使用TopOn Open API服务并将Publisher Key在第三方平台完成相关绑定，即表明您已明确理解、同意并充分授权第三方平台从TopOn获取广告策略或广告数据，具体功能和实现方式以《Open API 接入指南》所载为准。
2. 您明确理解并同意，您需要严格遵守与TopOn签署的线上或线下服务协议（含TopOn的隐私政策）的具体约定。TopOn没有与您的应用程序的最终用户建立直接的联系，因此，您承诺并保证，TopOn基于为您提供服务的目的而处理相关个人信息或数据时，您已向最终用户依法提供适当通知并获得用户的有效同意，并保证获取同意的方式、方法、程序等不会违反应适用的相关法律法规的规定。
3. 您明确理解并同意，您和第三方平台有义务对从TopOn 获取的数据的安全性、完整性负责，如因您或第三方平台的过失导致数据泄露或存在其他风险的，由过错方承担责任，与TopOn无关。您与该第三方平台之间或因使用该第三方平台的服务而产生的数据泄露或其他任何纠纷、责任、后果等，均与TopOn无关。
